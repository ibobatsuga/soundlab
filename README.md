## ⚡ Fitur Utama

- **Taksonomi Khusus Electronic & EDM:**
  - Subgenre: **Indobounce**, **Drift Phonk**, **Slap House**, **Hardstyle**, **Tech House**, **Festival Progressive**, **Cyberpunk Darksynth**, **Jersey Club**, **Drum & Bass**, **Melodic Dubstep**.
  - Drop Karakter: *Crispy & Bouncy*, *Melodic & Euphoric*, *Heavy Face-Melter*.
  - Vokal: *Female EDM Diva*, *Cyber Vocoder*, *Hype MC / Chops*, *Deep Pitch*, dan *Pure Club Banger (No Vocals)*.
- **Dual-Deck Master Audio Player:** Otomatis menghasilkan **Mix A** (melodic bouncy drop) dan **Mix B** (heavy 808 sub-bass drop).
- **Audio Waveform Visualizer:** Equalizer neon bar responsif bergaya dark cyberpunk (Obsidian + Neon Lime).
- **Interactive Audio Demos:** 4 sampel audio live bawaan yang bisa langsung diputar sebelum membuat lagu.
- **Payment & Workflow:**
  - Simulasi pembayaran QRIS dinamis (Rp 10.000 / 2 track drop).
  - Mode **Sandbox / Dev Bypass** untuk pengujian langsung tanpa biaya riil.
  - Direct MP3 download dan sharing ke WhatsApp dalam satu klik.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router, Server Actions & Route Handlers)
- **Styling:** Tailwind CSS (Dark Obsidian & High-Voltage Electric Lime `#d4ff00`)
- **Icons:** Lucide React
- **Engine:** Suno Electronic V6 AI Model Synthesis Pipeline

---

## 🚀 Menjalankan Secara Lokal

```bash
# Clone repository
git clone https://github.com/ibobatsuga/soundlab.git
cd soundlab

# Install dependensi
npm install

# Jalankan server development
npm run dev

# Buka http://localhost:3000 di browser
```
